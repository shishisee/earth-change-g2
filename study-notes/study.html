①세포호흡 모든 기관계가 일하는 까닭

세포호흡: 세포에서 영양소와 산소를 이용해 에너지를 얻는 과정. 이때 이산화 탄소와 물 같은 노폐물이 생긴다.

세포호흡은 폐가 아니라 온몸의 모든 세포에서 일어난다.

얻은 에너지: 체온 유지, 두뇌 활동, 근육 운동, 소리 내기, 생장

물질몸 밖과 주고받는 기관계세포까지 운반
영양소소화계 (흡수)순환계
산소호흡계 (들어옴)
이산화 탄소호흡계 (나감)
요소배설계 (나감)

②따라 쓰기

포도당(영양소) + 산소 → 에너지 + 이산화 탄소 + 물

세포호흡은 온몸의 모든 세포에서 일어난다.

영양소는 소화계, 산소는 호흡계로 들어오고 순환계가 세포까지 운반한다.

이산화 탄소는 호흡계로, 요소는 배설계로 몸 밖에 나간다.

③따라 그리기 세포를 둘러싼 네 기관계 · 화살표 방향을 정확히

소화계

이름

큰 영양소를 세포막을 통과할 수 있는 작은 분자로 분해(소화)하고, 작은창자에서 흡수한다.

①핵심 정리 기관마다 무엇이 무엇을 분해할까?

기관소화액 · 효소하는 일

식도없음근육의 꿈틀 운동으로 위로 밀어 내림
위위액: 펩신, 염산단백질 분해 시작 · 염산은 펩신 작용을 돕고 세균을 없앰
간 · 쓸개쓸개즙 (효소 없음)간에서 만들고 쓸개에 저장 → 작은창자로 · 지방을 작은 알갱이로 부숨
이자이자액: 아밀레이스 · 트립신 · 라이페이스작은창자로 분비 · 녹말, 단백질, 지방을 모두 분해
작은창자탄수화물 · 단백질 소화 효소소화가 끝남 · 융털에서 흡수 (포도당 · 아미노산 → 모세혈관, 지방산 · 모노글리세리드 → 암죽관)

②따라 쓰기

침 속 아밀레이스는 녹말을 엿당으로 분해한다.

위액 속 펩신은 단백질을 분해하기 시작한다.

쓸개즙은 간에서 만들어 쓸개에 저장하며, 소화 효소가 없다.

이자액에는 아밀레이스, 트립신, 라이페이스가 모두 들어 있다.

작은창자의 융털은 표면적을 넓혀 영양소를 잘 흡수한다.

③따라 그리기 소화관은 진하게, 간 · 쓸개 · 이자는 소화관 밖에!

순환계

이름

혈액 · 심장 · 혈관. 세포에 영양소와 산소를 주고, 이산화 탄소와 노폐물을 받아 온다.

①핵심 정리

혈액 성분하는 일
혈장 (액체)영양소 · 이산화 탄소 · 노폐물 운반
적혈구산소 운반 · 가운데 오목한 원반, 핵 없음
백혈구세균을 잡아먹음 · 핵 있음
혈소판상처에서 혈액 응고 · 가장 작음
혈관구조 → 기능
동맥벽이 두껍고 탄력 → 높은 혈압을 견딤 (심실 → 온몸)
정맥벽이 얇고 판막 → 거꾸로 흐름을 막음 (온몸 → 심방)
모세혈관벽이 세포 한 겹, 혈류가 가장 느림 → 물질 교환

심방 = 혈액이 들어오는 방, 심실 = 혈액을 내보내는 방. 판막은 혈액을 한 방향으로만 흐르게 한다. 벽이 가장 두꺼운 방은 좌심실.

폐순환우심실→폐동맥→폐→폐정맥→좌심방
온몸 순환좌심실→대동맥→온몸→대정맥→우심방

②따라 쓰기

혈액은 동맥 → 모세혈관 → 정맥 순서로 흐른다.

폐순환: 우심실 → 폐동맥 → 폐 → 폐정맥 → 좌심방

온몸 순환: 좌심실 → 대동맥 → 온몸 → 대정맥 → 우심방

폐동맥에는 산소가 적은 피, 폐정맥에는 산소가 많은 피가 흐른다.

호흡계

이름

공기 중의 산소를 받아들이고, 몸 안의 이산화 탄소를 내보낸다.

①핵심 정리

코→숨관→숨관가지→허파꽈리

숨관: 연골 고리가 있어 찌그러지지 않음

허파꽈리: 수억 개 → 표면적이 넓음, 벽이 세포 한 겹, 모세혈관이 감쌈

기체는 농도가 높은 쪽 → 낮은 쪽으로 이동 (산소: 허파꽈리 → 모세혈관, 이산화 탄소: 모세혈관 → 허파꽈리)

들숨날숨
갈비뼈올라감내려감
가로막내려감올라감
흉강 부피커짐작아짐
폐 안 압력대기압보다 낮음대기압보다 높음
공기몸 밖 → 폐폐 → 몸 밖

호흡 운동 모형: 고무막 = 가로막 · 고무풍선 = 폐 · 빨대 = 숨관 · 숨관가지 · 페트병 속 공간 = 흉강. 폐에는 근육이 없다!

②따라 쓰기

공기는 코 → 숨관 → 숨관가지 → 허파꽈리로 들어간다.

폐는 근육이 없어 갈비뼈와 가로막의 움직임으로 숨을 쉰다.

들숨: 갈비뼈 ↑, 가로막 ↓, 흉강 부피 ↑, 폐 안 압력 ↓

허파꽈리는 수가 많아 표면적이 넓고, 모세혈관이 감싸고 있다.

배설계

이름

세포에서 생긴 노폐물을 혈액에서 걸러 오줌으로 내보낸다.

①핵심 정리

단백질 분해 → 암모니아 → (간) → 요소 → (콩팥) → 오줌

콩팥→오줌관→방광→요도

콩팥 단위 = 토리 + 보먼주머니 + 세뇨관 (콩팥 하나에 약 100만 개)

과정방향무엇이?
① 여과토리 → 보먼주머니크기가 작은 물 · 포도당 · 아미노산 · 요소 · 무기염류 (혈구 · 단백질 X)
② 재흡수세뇨관 → 모세혈관필요한 물질 (포도당 · 아미노산은 전부)
③ 분비모세혈관 → 세뇨관남은 요소 등 노폐물

하루 혈액 약 1,500 L → 여과액 약 180 L → 오줌 약 1.5 L : 여과액의 약 99%가 재흡수된다.

②따라 쓰기

간은 해로운 암모니아를 요소로 바꾼다.

콩팥 단위는 토리, 보먼주머니, 세뇨관으로 이루어진다.

오줌은 여과 → 재흡수 → 분비를 거쳐 만들어진다.

포도당은 여과되지만 세뇨관에서 모두 재흡수되어 오줌에 없다.
