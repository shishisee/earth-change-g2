- 선생님 부탁: 친절하게. 기술적인 선택(구현 방식, 서비스)은 묻지 말고 Claude가 알아서 정하기.
  로그인·가입처럼 선생님이 직접 해야 하는 일만 요청하기.

## 파일 구조 (Vercel에 이 구조 그대로, 폴더 없이 평평하게 올라가 있음)
| 파일 | 역할 |
|---|---|
| index.html | 로더. /app 을 받아 와서 문서를 통째로 바꾸고 window.__PATCH() 실행 |
| app.html | 원본 사이트 (/app 으로 서빙됨, cleanUrls). 되도록 직접 수정하지 않음 |
| bank.js | 기관계별 문제 은행 (window.__BANK) |
| heart-fix.js | patch.js 보다 먼저 로드. window.__PATCH 대입을 가로채서, 패치가 끝난 뒤 heartMode(순환계 ② 심장 펌프)만 새 버전으로 바꿔 끼움 |
| patch.js | 개선판 덮어쓰기 (window.__PATCH). 단계 잠금, 숨쉬기·기체 교환·콩팥 실험실, 문제 은행 출제, 다음 단계 버튼 등 |
| teacher.html | 선생님 기록 페이지 (/teacher.html). PIN 입력 후 /api/records 조회 |
| api/record.js | 학생 활동 기록 저장 (Vercel Blob, records/*.json) |
| api/records.js | 기록 조회·전체 삭제. 환경변수 TEACHER_PIN 과 맞아야 함 |
| vercel.json, package.json | 설정 (@vercel/blob 의존성) |

로드 순서는 bank.js → heart-fix.js → patch.js 예요. heart-fix.js 가 반드시 patch.js 보다 앞에 있어야 해요.
뒤에 두면, /app 을 받아 와서 문서를 바꾸는 시점과 겹칠 때 실행이 안 될 수 있어요.

## 핵심 동작
- app.html 의 전역: SYS, ORDER, cur, curKey, mode, holders, runId, $, el, renderBody, setMode 등.
  SYS 는 const 라서 window.SYS 로는 안 보이고, 그냥 SYS 로 접근해야 함.
- 단계 잠금 (patch.js STEPS): 소화(스티커→여행→퀴즈) → 순환(스티커→심장 펌프→퀴즈) → 호흡(스티커→숨쉬기→기체 교환→퀴즈)
  → 배설(스티커→콩팥 실험실→퀴즈) → 통합 퀴즈.
- 교사 모드: 학생 화면 오른쪽 위 🔒 → 코드 2023 → 모든 단계 열림 (sessionStorage 'ys-teacher'=1).
- 선생님 기록 페이지 PIN: Vercel 환경변수 TEACHER_PIN (값은 선생님이 알고 있음).
- 순환계 심장 펌프 (heart-fix.js):
  - 몸 그림 속 원래 심장 칸(holders.ra/la 심방, rv/lv 심실)에 CSS 박동 클래스를 붙임 (그림 위에 덮어 그리지 않기!).
  - 혈구 하나가 SYS.circ.route.points (혈관 그림 위 점들)를 따라 돎.
  - 혈압 그래프는 왼쪽 몸 그림(#body) 바로 밑에 붙고, 단계를 벗어나면 사라짐.
